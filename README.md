# 🎓 Learning Management System (LMS) SMK Negeri 46 Jakarta

LMS SMKN 46 Jakarta adalah sistem pembelajaran berbasis web yang dikembangkan menggunakan **Laravel** dan **Tailwind CSS**.  
Sistem ini dibuat untuk membantu kegiatan belajar-mengajar di SMK Negeri 46 Jakarta agar lebih terstruktur, efisien, dan dapat menyesuaikan identitas visual sekolah.

---

## 🧭 Tujuan Proyek
Proyek ini bertujuan untuk:
- Menghadirkan sistem pembelajaran internal sekolah yang dapat di-host di server lokal.
- Menyediakan tampilan antarmuka yang mencerminkan identitas visual SMKN 46 Jakarta.
- Menggantikan platform eksternal seperti Google Classroom.
- Meningkatkan efisiensi guru dalam mengelola materi, tugas, dan penilaian siswa.

---

## ⚙️ Teknologi yang Digunakan
- **Framework:** Laravel 11  
- **Frontend:** Tailwind CSS  
- **Basis Data:** MySQL  
- **Metode Pengembangan:** Prototyping  
- **Pengujian:** Black Box Testing & User Acceptance Testing (UAT)

---

## 👥 Peran Pengguna dan Fitur Utama

### 🧑‍🎓 Siswa
- Registrasi akun dan login
- Edit profil dan ubah kata sandi
- Bergabung ke kelas sesuai jurusan
- Akses materi pembelajaran (file dan video)
- Unggah tugas dan lihat status nilai
- Terima notifikasi pengingat tugas
- Lihat riwayat tugas dan nilai akhir

### 🧑‍🏫 Guru
- Login dan ganti kata sandi
- Membuat, mengedit, dan menghapus kelas
- Menambah siswa ke dalam kelas
- Mengunggah materi dan tugas
- Menentukan tenggat waktu tugas
- Memberikan nilai dan umpan balik
- Mengunduh rekap nilai dalam format XLS

### 🧑‍💻 Admin
- Login dan ubah kata sandi
- Menambah, mengedit, dan menghapus akun pengguna
- Melihat seluruh data pengguna (siswa, guru, admin)
- Mengubah gambar jumbotron pada halaman utama

---
